# SHEEN — شِين

A vintage video studio for phone and desktop. Dark olive, wood and beige, a matching light theme, and a hand-drawn camcorder icon with an integrated S.

Upload a video, compare five camera-inspired looks, adjust grain, bloom, softness and color bleed, control date/time/camera overlays, trim and export MP4 or WebM. Video processing stays in your browser.

## Features

- DCR/TBC, Hi8, VHS, Video8 and MiniDV looks with distinct illustrations and sample previews.
- Themed keyboard-accessible menus, thumbnail timeline, play/pause/stop and before/after comparison.
- 12/18/24/30fps, 4:3/9:16/16:9/original crop, trim and optional audio.
- iPhone home-screen icon and PWA manifest.

## Run locally

Serve this folder with any static HTTP server. No build or package installation is needed. Production requires HTTPS for browser media encoding and offline features.

## Open source and assets

Mediabunny1.66.0 is bundled unchanged under MPL-2.0. Alexandria and Bodoni Moda use SIL OFL. Their license files are in assets. The lake sample is Luca Bravo / Unsplash; the demo is an animated-photo derivative, not original camcorder footage. Camera illustrations are authored SVG. The app icon is an AI-generated vintage sketch created for this project.

## Browser support

Export requires compatible browser codecs/WebCodecs. Start with short clips on mobile; accepted input is up to250MiB and memory use depends on your device. Presets are artistic interpretations, not hardware-certified profiles. Tested with Chromium; physical iPhone/Safari export still needs device testing.

On iPhone: open the site in Safari, Share, Add to Home Screen.
